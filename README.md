# Sam Portfolio Dashboard

Source for the portfolio dashboard deployed at
https://sam-portfolio-dashboard.vercel.app/.

The repository contains only the deployable percentage-based dashboard. Raw
Schwab exports, account balances, and local cash-flow calculations are excluded.

## Update policy

All production dashboard changes should be committed here alongside the Vercel
deployment. Keep the repository limited to deployable, percentage-based output;
never commit raw brokerage exports, account balances, credentials, or local
calculation workbooks.
